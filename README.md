# Browser Extensions for SOC Analysts

This repository contains browser extensions designed to simplify tasks for SOC analysts.

## Extensions

- **FastSearch_IPDB** – Quickly search a selected URL in `abuseipdb.com` by selecting it on a page and clicking the extension icon.  
- **FastSearch_VirusTotal** – Quickly search a selected Hash or URL in `virustotal.com` by selecting it on a page and clicking the extension icon. 
- **ReTab** – Easily rename browser tabs for better organization.

## Manual Installation

### Chrome / Edge
1. Go to `chrome://extensions/` (or `edge://extensions/`).  
2. Enable **Developer mode**.  
3. Click **Load unpacked** and select the extension folder.  

### Firefox
1. Go to `about:debugging#/runtime/this-firefox`.  
2. Click **Load Temporary Add-on**.  
3. Select the extension’s `manifest.json` file.
